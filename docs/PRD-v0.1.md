# 王冠三连棋 产品文档 v0.1

日期：2026-07-22  
状态：首个本地可玩版本

## 产品目标

将传统三子棋改造成具有地形、棋子等级、堆叠、移动和回收机制的轻量策略 H5 游戏。首版支持同设备双人对战，优先验证规则是否有趣、是否平衡。

## 规则基线

1. 棋盘为 4×4，开局随机生成两个不同位置的永久障碍。
2. 等级为国王＞王后＞护卫。先手拥有 1 国王、2 王后、4 护卫；后手拥有 1 国王、3 王后、2 护卫。
3. 每回合选择放置、移动或回收。
4. 放置可进入空格，或压住等级更低的敌方顶层棋子；不能压己方棋子。
5. 棋子允许多层堆叠，仅顶层可操作和参与胜负判断。顶层离开后下一层立即显露。
6. 移动只能前往上下左右相邻一格，落点规则与放置相同。
7. 回收会把己方顶层棋子放回库存，随后可以放置或移动一枚更低级棋子，也可以放弃。回收护卫合法但没有追加行动。
8. 顶层可见棋子在横、竖或两类斜线方向连续三枚即获胜；四连也包含三连。
9. 如果上层离开导致双方同时三连，由刚显露的下层棋子所属一方获胜。

## 首版范围

包含：本地双人、随机障碍、完整三种行动、合法落点提示、规则弹窗、重新开始、手机适配、规则自动测试。  
不包含：AI、联网对战、账号、排行榜、音效、云存档、后端和数据库。

## 后续验证

记录先后手胜率、平均回合数、障碍分布影响、回收使用频率和棋子库存剩余情况，再决定后手补偿是否调整。
