# 王冠三连棋 产品文档 v0.4

日期：2026-07-22  
状态：先后手补偿规则调整

## 调整目标

试玩观察显示原配置下后手胜率偏高，因此取消后手额外王后补偿，改为双方资源完全一致，并用“后手预置护卫”改变开局空间结构。

## 新开局规则

1. 双方基础库存均为：1国王、2王后、4护卫。
2. 开局先随机生成两个不同位置的障碍。
3. 系统从剩余合法空格中随机选择一个位置，放置后手的1枚护卫。
4. 该护卫从后手库存扣除，因此进入第1回合时：
   - 先手手中：1国王、2王后、4护卫。
   - 后手手中：1国王、2王后、3护卫；场上已有1护卫。
5. 预置完成后仍由先手开始第1回合。

## 美术识别调整

- 国王继续使用王冠造型。
- 王后改为独立的宝石徽记造型，以菱形宝石、侧翼装饰和底座构成，不再使用王冠。
- 护卫继续使用盾牌纹章。

## 后续验证指标

- 先手与后手胜率。
- 后手预置护卫所在区域与胜率的关联。
- 平均回合数。
- 预置护卫被压制、移动或回收的频率。
