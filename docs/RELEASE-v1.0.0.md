# 王冠三连棋 v1.0.0 发布说明

发布日期：2026-07-22

## 首个公开版本

v1.0.0 建立了完整可玩的核心规则、正式主菜单、本地双人模式和两档人机难度。

## 功能

- 4×4随机障碍棋盘。
- 国王、王后、护卫三级棋子。
- 放置、移动、回收和多层压制。
- 后手随机预置护卫的开局补偿。
- 同设备双人对战。
- 见习棋手与宫廷棋手。
- 桌面端和移动端响应式UI。
- 原创主菜单与对战背景。
- 自动化规则和AI测试。

## 已知限制

- 创意模式与王座棋手尚未开放。
- 设置界面暂不保存音频配置。
- 暂无在线账号、云存档、排行榜和联网对战。

## 开发方式

项目采用纯前端架构，无生产依赖，可通过任意静态文件托管服务发布。
