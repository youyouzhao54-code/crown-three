# 创意模式武将规则档案 v0.1

> 记录日期：2026-07-23  
> 适用范围：9×9 创意模式  
> 规则状态：开发测试版

## 文档维护约定

- 本文档用于保存每名武将的完整规则，不以选将界面的短描述代替。
- 修改武将名称、势力、简介、初始棋子、技能或关键判定时，必须同步更新武将档案。
- 后续更新创建新的版本文件，例如 `CREATIVE-GENERALS-v0.2.md`，不覆盖旧版本。
- 代码内的技能描述、对局 UI 提示、自动化测试和本文档必须保持一致。
- “盘面棋子”默认只统计最上层可见棋子；被压制棋子不参与数量、等级总和与连珠统计，技能另有说明时除外。
- 棋子等级默认限制在1～7级；降至0级或更低时消失。

## 刘三刀

- 势力：群雄
- 定位：快速获取高级棋子，积蓄充能后形成突破
- 简介：我部悍将刘三刀，擅长通过快速获取高级棋子形成突破胜利。
- 初始棋子：1级×16、2级×8、3级×4、4级×2、5级×1

### 【夺势】

放置或移动一枚棋子后，以本次操作棋子的落点为中心，检查己方可见棋子的连续连线：

- 二连：获得一枚2级棋子。
- 三连：获得一枚3级棋子。
- 四连：获得一枚4级棋子。
- 五连：获得一枚5级棋子。
- 同时形成多种长度的连线时，只取最高连数并获得一次奖励。

### 【蓄势】

- 1级棋子无需充能即可放置。
- 放置N级棋子需要至少拥有N-1点该等级充能，并在放置时消耗N-1点。
- 放置完成后，所有高于本次放置等级的等级各获得1点充能。
- 每个等级的充能独立计算且没有上限。
- 移动、回收以及非放置方式进入棋盘均不产生或消耗充能。

示例：放置3级棋子时消耗2点3级充能，随后4、5、6、7级充能各增加1点。

## 赵云

- 势力：蜀
- 定位：防守反击，利用敌方阵型强化棋子
- 简介：擅长防守反击，深入敌营，一击制胜。
- 初始棋子：1级×64

### 【陷阵】

- 放置棋子后，该棋子等级增加X。
- X为该棋子周围八个相邻位置中敌方可见棋子的数量。
- 棋子等级最高为7级。
- 回收己方棋子时，该棋子等级降低2级后返回手中。
- 回收后等级降至0级或更低时，该棋子消失。

### 【愈厉】

- 每累计放置两枚相同原始等级的棋子，获得一枚高一级棋子。
- 各等级分别累计。
- 移动不计入累计。
- 累计放置两枚7级棋子不会获得额外棋子。

### 【携幼】

- 赵云第一个自己的回合开始时，在随机空位生成一枚己方7级棋子。
- 该7级棋子不算放置，不触发【陷阵】或【愈厉】。
- 移动该7级棋子后：
  - 若原位置已经完全为空，在原位置放置一枚己方1级棋子。该棋子算放置，正常触发【陷阵】和【愈厉】。
  - 若原位置显露出被压制棋子，使最上方显露棋子等级+1，并将其返回该棋子的拥有者手中。
- 返回手中的棋子最高为7级。

## 陆逊

- 势力：吴
- 定位：依靠回合资源和劣势补偿逐步积累优势
- 简介：东隅已逝，桑榆非晚。
- 初始棋子：无

### 【谦节】

- 陆逊自己的奇数回合开始时，获得两枚1级棋子。
- 陆逊自己的偶数回合开始时，获得一枚2级棋子。
- 陆逊的奇数等级棋子可以无视等级，压制敌方偶数等级棋子。
- 陆逊的偶数等级棋子不能被敌方奇数等级棋子压制。

### 【逊礼】

陆逊回合结束时，先同时判断以下两个条件，再依次执行满足的效果：

1. 若陆逊的可见棋子数量少于对方，从陆逊手中所有实际棋子中随机抽取一枚，将其置入随机空位。此次置入不算放置。
2. 若陆逊的可见棋子等级总和少于对方，从陆逊手中所有1～6级实际棋子中随机抽取一枚，使其等级+1。

补充判定：

- 两个条件在任何效果执行前完成判断。
- 第一项置入的棋子不会改变第二项是否满足。
- 随机抽取以每一枚实际棋子为单位，因此库存较多的等级被抽中的概率更高。
- 手中没有符合条件的棋子或棋盘没有空位时，对应效果不执行。

## 吕布

- 势力：群雄
- 定位：以霸气限制换取强力压制能力
- 简介：虎牢霸关，举世无双。以霸气驱动强攻，在压制中愈战愈强。
- 初始棋子：2级×2、3级×3、4级×4
- 初始霸气：1
- 霸气上限：3

### 【霸关】

- 只要本局有吕布，双方均需要六连才能获胜。
- 吕布可以压制同等级敌方棋子。
- 吕布压制敌方棋子后：
  - 吕布棋子等级+1，最高为7级。
  - 被压制棋子等级-1，降至0级或更低时消失。
- 敌方棋子必须至少比吕布棋子高2级才能压制吕布棋子。

### 【单三】

- 吕布自己的回合开始时恢复1点霸气，最高为3点。
- 吕布执行一个完整行动需要消耗2点霸气。
- 霸气不足2点时不能进行常规行动，但若盘面存在己方5～7级顶层棋子，仍可选择发动【单三】。
- 回合结束时也可以发动【单三】。
- 发动时选择己方一枚5级以上顶层棋子，摧毁该位置的整叠棋子，包括下方全部被压制棋子。
- 若被选择的顶层棋子等级为X，获得两枚X-4级棋子并恢复1点霸气：
  - 摧毁5级：获得两枚1级。
  - 摧毁6级：获得两枚2级。
  - 摧毁7级：获得两枚3级。
- 可以选择不发动并结束回合。

## 张飞

- 势力：蜀
- 定位：消耗低级棋子强化手牌与盘面，通过数量劣势连续行动
- 简介：一声狂啸震军心，进退之间自有章法。
- 初始棋子：1级×12、2级×3、3级×1、5级×1

### 【狂啸】

- 放置1级棋子后，从手中所有1～6级实际棋子中随机抽取一枚，使其等级+1。
- 若此时张飞的可见棋子数量少于对方，可以继续行动。
- 追加行动可以主动结束。
- 追加行动中再次放置1级棋子且仍满足数量条件时，可以再次获得追加行动。
- 手牌中没有1～6级棋子时，升级效果不执行。

### 【肃军】

- 回收己方2级以上棋子时，不将该棋子返回手中，而是将其摧毁。
- 获得X枚1级棋子，X为被回收棋子的等级。
- 此次行为仍属于回收，保留“操作一枚等级低于回收棋子的棋子”的追加行动。
- 张飞可以将1级棋子放置在己方顶层棋子上：
  - 消耗该枚1级棋子。
  - 不形成新的堆叠。
  - 目标棋子等级+1，最高为7级。
  - 每枚棋子停留在盘面期间只能通过此方式强化一次。
- 强化标记随棋子移动或被压制保留；棋子离开盘面后标记清除。
