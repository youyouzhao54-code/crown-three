# 武将文档维护规则

武将规则发生变化时，开发工作必须同时完成以下事项：

1. 修改 `src/creative/roles.js` 中的武将资料和界面短描述。
2. 修改对应规则引擎与技能实现。
3. 修改或新增自动化测试。
4. 复制最新的 `docs/CREATIVE-GENERALS-vX.Y.md` 为新版本，并在新文件中更新完整规则。
5. 在新版本末尾记录本次变更；旧版本文件不得覆盖或删除。
6. 发布前核对代码、UI描述、测试和武将档案是否一致。

版本号建议：

- 单次小型数值或文字调整：次版本递增，例如 `v0.1` → `v0.2`。
- 多名武将重做或规则结构发生明显变化：主版本递增，例如 `v0.9` → `v1.0`。
