# 王冠三连棋 产品文档 v0.5

日期：2026-07-22  
状态：随机第一手与对战信息布局调整

## 调整目标

消除“后手预置棋子”容易被误解为额外行动或阵营错误的问题，并让玩家无需滚动页面即可同时看到对手、棋盘、己方库存与主要操作。

## 随机第一手规则

1. 双方基础库存均为：1国王、2王后、4护卫。
2. 开局先随机生成两个不同位置的障碍。
3. 系统从先手当前库存的7枚实体棋子中随机抽取1枚，因此国王、王后、护卫均可能被抽中，概率随库存数量计算。
4. 系统从合法空位中随机选择1格，将抽中的先手棋子放入棋盘，并从先手库存扣除该棋子。
5. 这次系统放置属于先手第一回合，不是额外行动。
6. 随机第一手完成后，回合数进入第2回合，并立即轮到后手行动。

## 人机对战信息规则

- 对手信息固定显示在棋盘上方。
- 玩家信息固定显示在棋盘下方。
- 界面明确显示“你操控金色/银色”以及“先手/后手”。
- 选择先后手时直接说明谁获得随机第一手，以及随机完成后由谁行动。
- 对战中持续显示随机第一手的简短说明。

## 布局目标

- 常见桌面浏览器窗口内不依赖滚轮完成主要对局操作。
- 保持4×4棋盘格为等大的正方形。
- 短屏幕下进一步压缩标题、图例、棋子卡片和按钮间距。

## 后续验证指标

- 随机到不同棋子等级时的先后手胜率。
- 随机第一手的位置与胜率关联。
- 玩家是否能正确理解随机棋子的归属和回合消耗。
- 常见桌面与移动设备上的首屏信息完整度。
