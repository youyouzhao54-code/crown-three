# 王冠三连棋 产品文档 v0.2

日期：2026-07-22  
状态：主菜单沉浸感升级，本地可玩版本

## 版本目标

在不改变 v0.1 对局规则的前提下，建立正式游戏产品所需的主菜单与模式入口，并统一“中古石质棋桌、古铜与月蓝阵营”的视觉语言。主菜单应让背景世界与界面融为一体，减少卡片、面板和矩形边框带来的网页感。

## 产品结构

### 主菜单

- 人机对战：首版只展示入口与“敬请期待”状态。
- 双人对战：进入当前完整的本地双人玩法。
- 创意模式：首版只展示入口与“敬请期待”状态。
- 设置：展示音乐、音效和落点提示项目，首版不持久化配置。
- 退出：由于浏览器限制，不主动关闭窗口，向玩家提供关闭页面提示。

### 双人对战

沿用 `PRD-v0.1.md` 的全部规则。对局内增加“返回主菜单”，返回时不播放完整开场动画。

## 主菜单体验要求

1. 背景图直接构成场景，不使用居中的实体卡片或大面积矩形面板。
2. 标题、菜单和背景通过暗部渐变融合，不依靠密集边框保障可读性。
3. 游戏标题使用可编辑的正确中文文字，通过碑刻字体栈、石质裂纹遮罩、古铜渐变与浮雕阴影呈现艺术感。
4. 菜单选项主要依靠字号、亮度、留白和动态区分层级。
5. 双人对战是当前唯一可进入的模式，使用金色状态文字突出。

## 动效规范

### 首次进入

- 总时长约 2.4 秒。
- 三层 CSS 雾气从中央向两侧散开并消失。
- 王冠、标题、说明文字和菜单按顺序显现。
- 标题由模糊、轻微缩放和宽字距过渡为清晰状态。

### 菜单悬停

- 文字转为柔和古铜金色。
- 选项向右移动约 4 像素。
- 两侧短装饰线展开，出现轻微光晕。
- 时长控制在 200–300 毫秒，不使用跳跃和强闪烁。

### 页面切换

- 进入双人对战时主菜单淡出并轻微放大。
- 返回主菜单时采用短淡入，不重复完整迷雾动画。
- 尊重系统的“减少动态效果”设置，自动关闭长动画。

## 美术资产

- `public/images/main-menu-bg-v1.png`：原创中古策略桌游背景。
- 标题当前为代码原生文字效果，保证中文准确、响应式缩放和无障碍读取。

## v0.2 不包含

- 人机算法。
- 创意模式规则编辑器。
- 设置持久化。
- 独立音频资源。
- 后端、数据库与在线功能。

## 验收标准

- 打开网页首先显示主菜单。
- 开场雾气、标题与菜单动画正常结束，结束后不遮挡交互。
- 双人对战能够进入并返回主菜单。
- 未开放模式具有明确反馈。
- 手机和桌面尺寸均保持文字可读、菜单可点击。
- 原有规则自动测试全部通过。
