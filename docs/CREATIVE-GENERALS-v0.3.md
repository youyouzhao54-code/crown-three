## 曹操新增技能

### 【篡汉】

- 当曹操在本局中已经发动过【归心】的最后一项（回合开始时手中至少有5枚5级棋子，并将这些棋子升为6级），在该次回合开始阶段结算完毕后、行动阶段开始前，必须进行一次抉择。
- 在完成抉择前，曹操不能放置、移动或回收。
- 选择“篡汉”：
  - 失去手中全部1～5级棋子。
  - 永久失去【归心】；以后回合开始时不再根据5级手牌数量触发【归心】。
  - 保留【奸雄】。
- 选择“放弃篡汉”：
  - 永久失去【篡汉】。
  - 保留【归心】与【奸雄】。
- 【篡汉】抉择每局仅进行一次；无论选择哪一项，之后都不会再次弹出。

## 阶段顺序

1. 回合开始阶段。
2. 结算【归心】；若满足最后一项，先将全部5级手牌升级为6级。
3. 进入行动阶段前，结算【篡汉】抉择。
4. 抉择完成后进入正常行动阶段。
