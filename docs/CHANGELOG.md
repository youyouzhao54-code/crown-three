# 文档与规则变更记录

## 规则与界面 v0.5 — 2026-07-22

- 取消“后手预置护卫”，改为先手第一手由系统随机完成。
- 系统从先手实际库存中随机抽取国王、王后或护卫，并随机放到合法空位。
- 随机放置计为先手第一回合，完成后立即轮到后手。
- 人机对战明确显示玩家与对手的金银阵营及先后手身份。
- 对局信息改为上方对手、下方玩家，并压缩为桌面端一屏布局。
- 在先后手选择、对战提示与规则弹窗中同步说明随机第一手。

## v0.1 — 2026-07-22

- 建立 4×4、双随机障碍的基础棋盘。
- 建立国王、王后、护卫三级棋子与先后手差异库存。
- 建立放置、移动、回收、堆叠与显露规则。
- 明确三连判断只看顶层，并记录同时三连的特殊裁定。

## UI v0.2 — 2026-07-22

- 新增带原创背景图的桌游风格主菜单。
- 增加人机对战、双人对战、创意模式、设置和退出入口。
- 当前仅双人对战可进入完整游戏，其余入口提供前端状态反馈。
- 增加从对局返回主菜单的入口。
- 移除中央实体面板和菜单按钮边框，改为背景融合式布局。
- 新增三层迷雾散开、标题锻造显现、菜单依次淡入和页面切换动画。
- 新增碑刻与古铜材质的代码原生艺术标题。
- 新增 `PRD-v0.2.md` 与 `UI-SPEC-v0.2.md`，保留旧版文档。

## 规则 v0.4 — 2026-07-22

- 双方基础库存统一为1国王、2王后、4护卫。
- 后手开局随机预置1枚护卫，随后由先手行动。
- 王后图标由王冠改为独立宝石徽记。
