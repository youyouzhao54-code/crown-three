# 文档与规则变更记录

## v0.1 — 2026-07-22

- 建立 4×4、双随机障碍的基础棋盘。
- 建立国王、王后、护卫三级棋子与先后手差异库存。
- 建立放置、移动、回收、堆叠与显露规则。
- 明确三连判断只看顶层，并记录同时三连的特殊裁定。

## UI v0.2 — 2026-07-22

- 新增带原创背景图的桌游风格主菜单。
- 增加人机对战、双人对战、创意模式、设置和退出入口。
- 当前仅双人对战可进入完整游戏，其余入口提供前端状态反馈。
- 增加从对局返回主菜单的入口。
- 移除中央实体面板和菜单按钮边框，改为背景融合式布局。
- 新增三层迷雾散开、标题锻造显现、菜单依次淡入和页面切换动画。
- 新增碑刻与古铜材质的代码原生艺术标题。
- 新增 `PRD-v0.2.md` 与 `UI-SPEC-v0.2.md`，保留旧版文档。

## 规则 v0.4 — 2026-07-22

- 双方基础库存统一为1国王、2王后、4护卫。
- 后手开局随机预置1枚护卫，随后由先手行动。
- 王后图标由王冠改为独立宝石徽记。
