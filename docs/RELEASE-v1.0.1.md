# 王冠三连棋 v1.0.1 发布说明

发布日期：2026-07-22

## 本次更新

v1.0.1 重新设计了开局随机规则，并优化人机对战的信息层级与桌面端一屏布局。

## 规则调整

- 先手第一手改为由系统随机完成。
- 随机棋子从先手实际库存抽取，可能是国王、王后或护卫。
- 系统将棋子随机放入合法空位，并从先手库存扣除。
- 随机放置计入先手第一回合，随后立即轮到后手。

## 界面优化

- 对手信息固定在棋盘上方，玩家信息固定在棋盘下方。
- 明确显示玩家操控的金色或银色阵营。
- 先后手选择与规则弹窗增加随机第一手说明。
- 压缩对战页纵向空间，常见桌面窗口无需滚动即可看到主要对局信息和操作。

## 验证

- 8项自动化规则与AI测试全部通过。
- 已验证先手和后手两种人机选择下的阵营布局与回合提示。
- 已验证1146×912桌面视口内完整显示主要对局区域。
