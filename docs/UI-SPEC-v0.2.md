# 主菜单 UI 与动效说明 v0.2

## 设计关键词

无框、克制、沉浸、电影感、慢节奏、材质统一。

## 字体层级

- 游戏标题：楷体/碑刻感中文字体栈，古铜渐变、暗色裂纹与浮雕阴影。
- 模式名称：楷体或仿宋风格，保持清晰，不施加强烈破损。
- 状态与说明：系统无衬线字体，提高小尺寸可读性。
- 英文装饰文字：Georgia 等古典衬线字体。

## 色彩

- 背景：炭黑、冷蓝灰。
- 主强调：磨损古铜金。
- 次强调：月光蓝灰。
- 禁止大面积纯金和高饱和蓝，避免廉价发光感。

## 交互原则

- 默认状态保持安静，只有当前指向的入口产生光线和位移。
- 动效只用于建立氛围、解释层级与确认操作。
- 未开放功能可点击获得提示，但不能误导玩家进入空页面。
