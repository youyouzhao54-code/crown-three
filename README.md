# 王冠三连棋 Crown Three

一款运行在浏览器中的原创 4×4 轻策略棋盘游戏。在传统三连棋基础上加入障碍、棋子等级、压制堆叠、移动和回收机制。

> 当前版本：v1.0.0

## 在线试玩

GitHub Pages 发布完成后可通过以下地址游玩：

https://youyouzhao54-code.github.io/crown-three/

无需安装，也不需要注册账号。支持桌面浏览器和手机浏览器。

## 核心玩法

- 4×4 棋盘，开局随机生成两个障碍。
- 棋子等级：国王 ＞ 王后 ＞ 护卫。
- 双方基础库存均为1国王、2王后、4护卫。
- 后手开局随机预置1枚护卫，随后由先手行动。
- 每回合选择放置、移动或回收。
- 高等级棋子可以压住低等级敌方棋子，支持多层堆叠。
- 只有顶层棋子能够行动和参与胜负判断。
- 横、竖或斜线方向连续3枚己方顶层棋子即可获胜。

完整规则见 [`docs/PRD-v0.4.md`](docs/PRD-v0.4.md)。

## 游戏模式

- 双人对战：同一设备轮流操作。
- 人机对战：支持选择先后手。
  - 见习棋手：基础战术与随机决策。
  - 宫廷棋手：Minimax、Alpha-Beta剪枝与限时搜索。
- 创意模式：规划中。

## 本地运行

需要 Node.js 18 或更高版本。

```powershell
npm.cmd start
```

打开：<http://127.0.0.1:4173>

运行自动测试：

```powershell
npm.cmd test
```

## 项目结构

```text
├─ index.html              # 网页入口和界面结构
├─ src/
│  ├─ app.js               # UI状态与玩家交互
│  ├─ styles.css           # 视觉、动画和响应式布局
│  └─ game/
│     ├─ engine.js         # 独立游戏规则引擎
│     └─ ai.js             # AI行动生成与搜索
├─ public/images/          # 原创游戏背景
├─ tests/                  # 规则和AI自动测试
├─ docs/                   # 历史产品文档与版本记录
└─ scripts/serve.js        # 零依赖本地静态服务器
```

当前版本完全由前端实现，不需要后端和数据库。
